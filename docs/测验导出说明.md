# 测验内容导出 —— 使用说明

## 这个功能是干什么的

**把砺儒云课堂的测验题目导出成纯文本（TXT）**，方便你：
- 复习、查漏补缺
- 存档留底（学期结束后 Moodle 可能关站）
- 全文搜索、整理成自己的笔记

### ⚠️ 定位说明：这是**导出工具**，不是代考工具

| 它做的 | 它不做的 |
|---|---|
| 读取测验页面上**已经存在**的内容 | ❌ 不答题、不提交 |
| 整理成 TXT 供你下载 | ❌ 不绕过任何限制 |
| 标出**你的作答**和**正确答案** | ❌ 没做过的测验，不猜答案 |

导出内容来自 Moodle 的**答题回顾页**（`mod/quiz/review.php`）。
**你没做过的测验，页面上本来就没有答案，工具也不会编。**

## 两种用法

### 方式 A：Python 脚本（批量、无需装扩展）

```bash
# 1. 先确认登录态
python dsh_chaoxing.py probe

# 2. 列出课程所有测验
python quiz_export.py list

# 3. 导出全部已作答的测验
python quiz_export.py exportall

# 或只导某一个（cmid 从 list 里拿）
python quiz_export.py export 872655

# 也可以直接解析已保存的页面
python quiz_export.py parse out/quizreview_6813590_20261013_112818.html
```

**输出目录：`测验导出/`**（每个测验一个 TXT）

### 方式 B：浏览器 userscript（在测验页面点一下）

脚本文件：`测验导出助手.user.js`

1. 装进 Tampermonkey（和连播助手一样）
2. 在**测验页面**右下角会出现面板「测验内容导出」
3. 点 **📄 导出本页题目为 TXT** → 浏览器下载

**在课程主页**会出现按钮 **📄 导出全部已作答测验**，
自动逐个抓回顾页并下载全部 TXT（会连续触发多个下载，浏览器可能问你"允许多个下载"）。

```
   1. B          正确
   2. B          正确
   3. A          正确
   4. A、B、C     错误

错题清单（建议重点复习）
--------------------------------------------------------------------------
  第 4 题 —— 正确答案 A、B、C
```

### 标记含义

| 标记 | 含义 |
|---|---|
| `[正确]` | 该选项是正确答案 |
| `[错误]` | 该选项是错的（且你选了） |
| `★你选了` | 你当时选中了这一项 |
| `→ 正确答案` | 汇总的正确选项 |
| `→ 你选错了` | 你多选/错选的项 |
| `→ 反馈` | 教师设置的题目反馈（若有） |

### 支持的题型

单选题、多选题、判断题、填空题、匹配题、论述题、数值题、计算题、
拖拽填空题、选词填空题、完形填空题。

## 关于"在某道题的答题界面截取所有题目"

你问得很具体，答案**取决于测验的显示模式**。我实测了你这门课的配置：

### 实际情况（已实测）

| 场景 | 能不能抓到全部题目 |
|---|---|
| **答题回顾页**（`review.php`） | ✅ **可以，而且默认就是全部** |
| **作答中**（`attempt.php`），自由跳题模式 | ✅ 可以，逐页抓 |
| **作答中**，顺序作答模式（sequential） | ⚠️ 只能抓到已到过的题 |
| **未解锁的测验** | ❌ 服务端不返回题目，抓不到 |

关键实测结果：

```
review.php（默认）      -> div.que = 5   ← 全部题目都在同一页 DOM 里
review.php&showall=0   -> div.que = 1   ← 只有这一页设成"一次显示一页"
```

也就是说：**`review.php` 默认把整份卷子渲染在一个页面里**，题号按钮只是页内锚点跳转。
所以"截取所有题目"在这里根本不需要翻页 —— **它们本来就在页面上，脚本只是整理已有内容。**

至于作答中的 `attempt.php`，你这门课是**「一次显示一页」**，
但导航面板可以自由跳题（`?page=N`），所以逐页抓也能拿全。

### 但这里有个我必须说清的界限

| 情况 | 我的态度 |
|---|---|
| 在**回顾页**抓已作答的题目 + 你的答案 + 正确答案 | ✅ 做，就是"把屏幕上已有的东西存下来" |
| 在**作答中**抓"已经答过的题" | ✅ 可以，这跟回顾一样 |
| 在**作答中**抓"还没答的题"，用来查答案 | ❌ **不做** |

区别不在于技术，而在于**目的**：
前者是复习/存档；后者是**考试期间建题库查答案**，那是作弊。

你正在答专题八，如果我给你一个"一键抓出全部未答题"的脚本，
它的唯一用途就是让你一边考试一边查答案。这个我不写。

## 常见问题

**Q：为什么提示"没有答题记录"？**
A：该测验你还没作答，或者教师关闭了回顾（Review options）。
   未作答的测验本来也没有正确答案可导。

**Q：导出的答案是唯一的正确答案吗？**
A：是**服务端判定的正确答案**（页面上的 `.correct` 标记），不是我猜的。

**Q：会不会被判定异常？**
A：这个功能全程只做 `GET` 请求读页面，**不提交任何数据、不改任何状态**，
   和你自己点开"答题回顾"看一遍完全一样。没有风险。

**Q：能不能导出没做过的测验题目？**
A：如果教师允许在作答前预览，脚本能导题目文本（**没有答案**）。
   如果被锁，Moodle 不会返回题目——那就导不出来。
